# Bounded quantifier component review (partial W09)

The reviewed scope is the shared contract compiler's finite integer quantifier
recipes, canonical W03 definedness aliases, literal range preflight, and their
new core/source fixtures. Other W09 components remain outside this checkpoint.

The range convention follows the user's explicit clarification: half-open
endpoints, false definedness for reversed intervals, and generation rejection
for statically oversized expansion counts. Direct literal bounds are checked
before recipe/network emission. Symbolic bounds use the same full-width range
predicate and cannot be accepted through low-word truncation.

The unsigned subtraction represents the mathematical distance for ordered
signed as well as unsigned endpoints, including a signed zero crossing. Its
complete width is compared with the capacity before count narrowing. The
lower-plus-offset calculation retains the source width and cannot overflow an
admitted interval. Empty forall is true; empty exists is false. Invalid bounds
produce false definedness and a zero count before body traversal. Shared lets
keep the range check outside the repeated count selector lambdas.

Both quantifier tags register universal body definedness, independently of the
existential value reducer. The original W03 term supplies bound-expression
definedness, lexical lets, nested binders and conditional guards. Nominal
function signatures remain exact even where the physical integer carrier is
shared. Source public consumers still reject partial clauses pending use-point
discharge; the new functions do not introduce an axiom or application proof.

Review found an evidence-preservation gap in the initial core test helper:
without an output environment variable, it did not compare generated bytes
against the checker fixture. The helper now checks both certificate and metadata
in normal runs. The short body-non-evaluation test also verifies that exact pin;
the unchanged full-capacity semantics need not be repeated for this test-only
correction. Initial test-only compile errors and an omitted entry-argument
assignment are retained in the verification logs rather than hidden.

A second coverage finding was that the full-capacity predicate was constant,
so it did not demand the high offset bits. The added targeted regression
extracts the actual predicate-cube argument from both emitted reducers, checks
they share that term, and evaluates it with the original binder environment.
All 14 selector bits, carry boundaries, signed zero crossing and high unsigned
values pass 320 independent expected-value observations in 15.68s. This uses
the already pinned certificate and does not regenerate a separate test formula
or repeat the full 16,384-element traversal.

The final component review has no actionable findings. Source/core tests,
inventory and affected lint/format checks passed. Both unchanged checkers
accepted all six identical-byte candidates with zero axioms and matching
reports, and rejected actual hash corruption. The terminal PASS names match
current candidate hashes, sizes, metadata and tested output copies. See
`unit-4-quantifier-progress.json` for the complete verification receipt.
This review is not an original-unit or W09 completion receipt.
