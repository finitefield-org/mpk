# Source-value result relation review

The emitted body reuses the existing checked source-product constructor or
field projection. Source signatures are reconstructed from the same validated
roots/closed instances as VIR, not accepted from a caller-supplied helper name.
Only the two source-value tags are admitted, and their empty ordered checks and
failure tables are enforced. Every original SSA use point and other-family
pending definition ID is retained exactly.

The result relation binds computed output once and compares the complete
physical carrier with the result subject. Under that Let the computed value is
index 0 and the actual result is index 1. Original operands retain their ordered
subject indices through the existing W03 predicate compiler. Physical equality
preserves representation details even for non-reflexive semantic types. It is
ordinary Bool recursion with no host observations, axioms or theory primitive.
Builder and final structure checks enforce the unchanged binder/term limits.

The import path independently regenerates canonical metadata and certificate
bytes from the original VIR. Tests reject substitutions of source/foundation/VC/
certificate hashes, a different source context with the same type ID, storage
or relation symbols, SSA successor, and corrupted certificate bytes. Existing
operation bodies and predecessor pins are unchanged by the new adapter.

Direct review caught a test-oracle assumption: captured members have names and
source types but no preassigned member ID. The oracle now derives each member
ID through the frozen stored-member identity function from the original facts,
then uses captured field order to choose the expected value. The early failing
log is retained separately; current runtime checks pass with this correction.
The namespace inventory delta is exactly one newly added source path; removing
it reproduces the previous path-set hash, with the aggregate count incremented
from 4,954 to 4,955 and historical cache correction relinked.

Coverage is intentionally distinguished from native-body proof: constructor
execution, property effects, public domains, ownership and CFG path conditions
remain separate outstanding obligations. In particular a broken constructor
source does not become accepted merely because its field read is well-defined.
The existing scalar storage helpers and new exact comparator are verified here,
not a universal application theorem. This is progress within unit 5, not its
commit/completion boundary; W09 and W10 readiness are unchanged.
