# Recursive public domains

Seven original construction-source programs add all compiled source public
clauses to representation membership. Product fields, active collection elements
and active sum payloads use recursively filtered child counts. Invalid public
clauses retain the saturated 65,537 sentinel; inactive storage still follows
representation zero-padding rules.

The source test passed in 2,373.31 seconds: six non-enum source contexts each
check full 32-bit logical counts at -1/0/1 and a validity predicate at zero,
including the string-bearing initializer layouts. The enum context is generated
and reconstructed; enum domain/default checks are also covered by the separate
predecessor and public-default tests. All standalone source-clause definition
closures are unchanged. These are domain predicates, not constructor proofs.

All seven pinned candidates passed unchanged Rust/Go same-byte checking with
zero axioms and actual hash-corruption rejection (315.648 seconds including
compiler queue). Exact PASS sets and current module hashes were reconciled.
Maximum costs are 8,358 terms, 237 declarations and 2,100 static transformers.
