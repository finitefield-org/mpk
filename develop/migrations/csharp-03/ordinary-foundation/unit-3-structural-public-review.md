# Structural public profile: direct component review

The new profile shares storage and scalar definitions with the original
structural program, then adds public-domain/default roots after every original
operation and observation definition. Clearing only the count cache before the
public pass prevents representation counts from suppressing recursive source
clauses. Existing operations retain their representation-domain dependencies;
source/public obligations are explicit, not silently assumed.

Review identified duplicate scalar-domain emission when both profiles occupy
one builder. `Domains::scalar` now reuses the already generated scalar predicate
for the same reconstructed carrier. The builder remains private and all entries
come from the same validated VIR. No caller-supplied definition is admitted.
The original plain generator's bytes are separately checked. Source-clause and
public-domain/default emitters were extracted without changing their standalone
bodies; all six pinned public-default programs passed exact replay.

Three original contexts passed complete transitive-definition comparisons with
both predecessor components, metadata matching, exact import and profile/field
mutation rejection. The source-clause mutation uses an invalid field type because
a no-clause source legitimately has an empty clause list. The profile binds the
source IR/foundation and clause source/attachment/expression identities and
reconstructs every supplied artifact on import.

No further component finding was identified in this review. All three current
candidates passed both unchanged checkers with zero axioms and hash-corruption
rejection. Exact predecessor structural/representation bytes, affected lint,
formatting and inventory checks also passed; receipts are in the progress record. Deep
recursive runtime checks and complete native/proof assembly remain separate open
work; this is not a clean whole-unit review or W09 completion receipt.
