# Typed primitive JSON packet review

Scope: W09 unit 4 primitive parser results used by the subsequent compound
grammar. This component does not implement source products/enums, semantic
containers/sums, field presence, complete boundary relations or application
proofs. Every carrier without a decoder remains explicit in `deferred_type_ids`.
Units 3–8 and W09 acceptance remain incomplete.

The new ordinary functions call the existing strict JSON token definitions with
the original document, absolute start and ending. Their result uses one role
selector: role zero holds the padded C7 header (valid, at EOF, absolute u32 end,
u32 logical cell count); role one holds the exact reconstructed value carrier.
The padded depth is `max(7, carrier.depth) + 1`. Invalid results clear the entire
packet. A primitive, including a complete string, contributes one logical cell,
matching the reference boundary decoder's value-cell accounting. Compound
composition must subsequently add and bound child counts and depth.

Review checked all scalar payload offsets and end offsets (C7: 2/66, C8: 2/130,
C10: 2/514), carrier padding, zero-width unit storage, exact float/GUID bits and
all 512 bits of the decimal carrier. Decimal adapters retain all 146 registered
normalized/fixed configurations, including scale and rounding linkage. Public
JSON kinds without a BoundaryCodec (unit/bool/char/string) use the local
`json.null`, `json.bool`, `json.char` and `json.string` route labels; these labels
do not add entries to the registered boundary codec set.

The string frame is bound once with an ordinary Let. Its complete C19 payload
is retained, while its decoded character length is replaced in the header by
the logical cell count one. Endings 0–3 remain value endings; colon and every
other ending reject, including when the underlying field-name frame succeeds.
The result assembly gates both roles on header validity. Projection definitions
select the role and fill only upper padding selectors with false, preserving
the full value depth and clearing unused header storage.

Source generation found a real shared-definition bug: the converter's cache
looked for its logical ID, but the circuit emitter returned a generated result
name. Two types sharing one layout attempted duplicate emission. A stable
ordinary alias now names each converter, and tests verify that repeated requests
return that exact alias without adding declarations or static transformers.
No Builder counter is reset and no existing primitive is hidden from accounting.

Targeted runtime tests cover 40 complete scalar packets plus all header/value
projection bits, and 24 complete string headers with sparse value probes up to
the last C19 address. Every invalid ending bit is individually exercised, and
nonuniform cursor bits detect accidental permutation or length substitution.
These are packet wiring tests; they do not claim that arbitrary synthetic input
packets independently satisfy lexical or value domains.

Seventy-two original contexts generate seven complete programs. The test
independently reconstructs expected token/type/configuration routes, verifies
the deferred carrier complement, rejects metadata and certificate mutations,
and compares every existing token declaration and dependency with the new
environment. A separate source-free matrix covers all 20 supported primitive
types, both GUID formats and all decimal configurations: 166 adapters in one
certificate, 219,046 terms, 3,010 declarations and 8,117 static transformers.
This matrix complements rather than replaces the original-source cases.

Eight distinct generated byte vectors are pinned with exact readback. Current
same-byte dual checking passed for all eight vectors (terminal session 2890,
exit 0, 3203.674s), with matching reports, zero axioms and hash-corruption
rejection; retained evidence is in `unit-4-json-values-progress.json`. The first checker attempt
could not open the macOS Go build cache and terminated before verification;
the retry uses a writable temporary Go cache. Existing token runtime matrices
are not repeated for this adapter change: complete dependency preservation and
the affected packet tests cover its impact. Outstanding earlier semantic jobs
remain separate.

Next, compound grammar must consume these typed results together with exact
field-name/punctuation matchers, enforce required/optional/null fields, ordered
members, bounds and cumulative cells, and supply actual boundary propositions
and proofs. No component-only commit is made, and the whole gate remains
deferred to T06-W12.
