# Additional original-source recursive-domain cases

`requests.json` contains five original C# inputs and, where needed, exact
semantic binding sidecars produced by the normal source-artifact builder.
`responses.json` contains their fresh Roslyn captures. All five captures were
accepted, then independently imported through `ValidatedDataSource` and
`emit_data_phase` before ordinary domain generation. Compiler output is source
evidence, not proof authority.

The cases cover string map keys, decimal map keys, decimal set elements,
compound keys containing a string and integer, and an array of source Item
records for the cumulative logical-cell boundary. Every concrete reachable
domain, including uninvoked instances, is included in the domain corpus.

An Item has fifteen integers and one nullable Bool. With an absent Bool it
contains 17 logical cells. A sequence of 3,855 Items therefore contains exactly
65,536 cells including its sequence cell. Changing the first nullable Bool to
present adds exactly one payload cell without changing the physical carrier or
sequence length. The core-domain test checks the valid boundary and rejection
at 65,537 against independent MonomorphicValue validation and counting.
That semantic test is still running; the captures and accepted definition
certificates alone do not prove those two outcomes.

Request regeneration is explicit:

```sh
MPK_W09_DOMAIN_REQUESTS_OUT=/tmp/mpk-w09-domain-source-requests.json \
  cargo test -p mpk-vc --test csharp_practical_vc \
  csharp_03_t06_w09_domain_boundary_source_requests -- --nocapture
```

The capture uses the existing `--test-data-phase-requests` harness and frozen
build-input cache. On this macOS workspace it was run in the existing local
Linux amd64 development image, with the repository mounted read-only, network
disabled and only temporary container output. The script independently checks
its compiler, reference assemblies and runtime against the frozen hashes and
runs the compiler/runtime in its existing isolated network namespace. No build
manifest, reference inventory or frontend source was changed for these cases.

The normal request test compares exact generated bytes with the pinned file.
The source-domain generator and import-mutation test consumes these five rows
alongside the earlier 21 sources. Two accepted exception-control sources in
`../exception-domain-sources/` extend the dual-checker corpus to 28 certificates. Root observation tests for string/compound maps now use sparse concrete Boolean
inputs to avoid allocating C33/C34 storage densely. The sparse layout agrees with
the existing dense encoder on smaller original-source maps, and the observer
still reduces every demanded ordinary term. The string/compound domain outcomes
are under verification; generation and input checks are not their substitute.
