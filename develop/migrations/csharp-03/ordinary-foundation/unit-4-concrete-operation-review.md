Scope: internal unit 4 of CSHARP-03-T06-W09. This is a definition component,
not application proof completion or a W09 completion receipt.

The adapter consumes every original closed operation recipe, including uninvoked
operations. Typed component metadata must agree with the exact argument/result
types and ordered failure labels. When an original VIR signature exists, its
arguments, result and ordered required checks must agree too. Missing, duplicate
or unconsumed component operations reject linkage.

A private extension point appends declarations to the same owning structural
builder before its one final certificate encoding. The original standalone,
boundary and public profiles use a no-op extension. Preservation tests compare
previous bytes and the complete transitive closures of component definitions.

The actual and concrete normal definitions have separate names and both resolve
to the exact component body. Every failure adapter retains its original operand
selection. First-failure predicates mask only later failures, success requires
all failures to be absent, and AllOutcomes compares selected failure/success
states plus the complete normal value when successful. Returned sum payloads
remain part of normal value observation. The comparison uses source observation,
including IEEE NaN payloads, rather than potentially non-reflexive value equality.

free-index order. Tests compare each original W06 assumption and goal AST after
only application regrouping. Conditions retain their original input assumptions
and normal-result guards; no constant truth or recipe hash discharges a sequent.
All original application proof IDs remain pending.
