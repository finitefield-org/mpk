# Ordinary public-default predicates

These six original-source programs extend recursive public domains with the
existing structural default candidates and a closed ordinary Bool for each
storable carrier. The Bool requires both declared public-default admission and
public-domain membership of the actual default candidate. An unavailable
structural default returns false. This emits a predicate; it does not prove an
application VC or assume a source invariant.

`certificates.json` retains exact source/foundation/construction linkage, original
default metadata, clause definitions, domain roots and final predicate names.
Plain public-domain generation omits this extension; each importer independently
regenerates its own complete profile and rejects cross-profile substitution.

Targeted source tests passed in 9.93 seconds for positive/broken defaults, a
constructor context, zero-valued enum, direct/array/nullable nested source, and
seventeen recursively nested sources declaring public defaults. Tests separate
structural eligibility, the captured public-default declaration and actual
public-clause membership. Nullable None does not depend on its type argument's
default or invariant. The array has no structural CLR public default. All
original default and public-domain definition closures are retained exactly;
metadata mutation and profile-substitution checks reject.

All six bytes were hash-verified before publication. Maximum costs are 8,022
terms, 229 declarations and 2,100 static transformers. All six candidates passed unchanged Rust/Go same-byte checking with zero axioms
and hash-corruption rejection (71.106 seconds including queue). The exact PASS
set and current candidate hashes were reconciled. Affected lint and consumer
inventory checks also passed; records are in `../unit-3-public-domains-progress.json`.
Deep recursive-domain runtime checks and the remaining W09 implementation/proof
assembly are still open. No internal-unit or W09 completion is claimed.
