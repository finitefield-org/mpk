# Binding representation conditions — partial W09

The new private condition program composes the original W06 member agreement,
exactly-one-arm, tag/payload agreement, semantic bound, canonical order/uniqueness
and nonempty-invalid sequents from the exact validated VIR. It includes the
existing source clauses, projections, complete comparison predicates, guards,
orders and recursive public domains. The stored original sequent retains every
assumption and goal; the emitted Bool condition means that their conjunctions
form an implication. Boolean connectives use the checked foundation definitions.

This program supplies definitions, not universal proofs. Every original binding
VC remains in `pending_proof_ids`; conditions outside the six implemented kinds
remain in `pending_condition_ids`, and unresolved constants remain explicit.

default admission, native-operation witness or accepted application result.
Those remaining W09 requirements are unchanged.

`OrdinaryBindingCondition` record. Its public obligation type remains an alias,

and the new conditions use `representation`. The order emitter's private loop
is extracted without changing traversal or emitted terms. Verification compares
all existing reconstruction bytes/metadata after the complete original semantic
run, plus all existing guard/order pins and transitive definition closures.
