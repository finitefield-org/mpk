## Original proposition and complete operands

W06 `concrete_type_equivalence` has one original subject, no assumptions and a
proof-level `Binding.Equal.Bool` goal between the recursive public-domain call
and its concrete-type wrapper. This binding equality describes agreement, as
documented in `csharp_practical_ordinary_binding_relations.rs`; it is distinct
from the C# value foundation's comparison operation.

The new generator reconstructs the entire original concrete-type program from
validated VIR and lowers those exact left and right operand ASTs to
`Std.Eq Std.Bool left right` under the original universal cube subject. It uses
the existing sealed reconstruction symbol map. The concrete wrapper already
calls the complete public-domain definition, so ordinary delta/beta conversion
allows `Std.Eq.refl` to check without assuming a free Boolean is a literal.
Source clauses, role/cumulative bounds, active payload domains and padding remain
inside the original recursive operands. No operand, source assumption or VC
identity is substituted. Proposition and theorem names bind the complete
original program hash and original sequent.

`Builder::resume` preserves original term/global indices, module, imports,
source manifest and all original declaration bodies. The existing Boolean
condition definitions and all 45 original concrete-type certificate pins remain
unchanged. Only the fixed registered ordinary Eq foundation and new named
proposition/theorem declarations are appended. No kernel, certificate-v0 rule,
recursor interface, primitive, axiom or C# theory handler is changed.

Ten original contexts have no public concrete-type condition. Their proof list
is empty, their original certificate bytes are returned unchanged and their
other obligations remain pending. The six exact internal construction-state
instances remain separately pending. An empty expected group does not authorize
omitting a required condition in a nonempty group.

true in generated metadata; linking a candidate does not discharge application
acceptance.

The integration test reconstructs all 45 actual source contexts, preserves the
original sequents and certificate prefixes, checks the universal named Eq types,

rejects each metadata field mutation, a foreign original context, wrong
