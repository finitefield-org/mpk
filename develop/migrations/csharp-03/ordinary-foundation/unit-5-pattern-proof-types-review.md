# Original pattern proof types — source checkpoint, verification in progress

The new private generation route preserves the complete source-route program
and adds ordinary proposition types for native/capture/observation premises.
Each premise is `Std.Eq Std.Bool (component arguments) Std.Bool.true`.
The scope proposition conjoins every component in its original order using
the frozen `Std.Logic.And` interface. A separate closed Pi refinement type
quantifies the complete physical environment, requires this scope proof and
concludes the exact original source predicate's truth. It neither asserts
execution nor supplies the refinement proof.

The generator publishes ordinary projection theorems for each scope component,
using the frozen conjunction recursor. Equality and logic are copied from their
hash-pinned standard certificates; existing complete private foundation copies
are reused, while partial copies reject. No axiom, C# kernel rule, proof-node
entry or theory certificate is added. Both checkers accept a universal projection
fixture under free Boolean arguments and reject a fully encoded incorrect proof
at core type checking, rather than a hash or format barrier.

The original corpus has 113 paths and 703 components. Its five large environments
retain every argument/component and remain explicitly pending at the combined
binder bound. The intended remaining coverage is 108 source-refinement types
and 664 component projections; the complete source-derived replay is still
running at this source checkpoint and these totals are not yet claimed as
verified. Six contexts had completed their exact preservation and kernel checks
when this checkpoint was recorded.

Four affected scope units, the ownership normalization unit, Clippy (including
unit/integration targets after the new development dependency) and format pass
locally. The new complete source regression checks original declaration bodies,
all original source goals and binding indices, every premise/conclusion binder,
zero axioms and actual kernel acceptance. The fixed source checkpoint is used
for the specified Linux replay; its result is pending. Verification receipts and
the explicit targeted-test selection are under
`verification-logs/control-predicates/with-pattern-proof-types/`.

Source refinement, execution establishment, the five large environments and
all 987 original application proofs remain open. Unit 5 and W09 stay In progress;
the full T06 gate remains deferred to W12.
