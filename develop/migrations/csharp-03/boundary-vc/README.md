# T06-W07: canonical boundary VC handoff

`BoundaryVcProgram` generates pending ordinary relations from the exact boundary
contracts retained by independently validated VIR. The existing VC wire commits
the complete program hash and sequent IDs. W07 groups depend on applicable
construction, data, control, exception and binding groups; nodes, declarations,
binders and shared definition names participate in the existing resource gate.
Standalone import rederives the program and requires exact canonical bytes.

For each boundary, input acceptance is a Boolean equivalence with the complete
canonical grammar, root-object shape, decoded-name uniqueness, known fields in
declaration order, and fixed limits. JSON syntax cells have a 262144 limit;
decoded values including frozen defaults have a separate 65536-cell limit.
The document byte limit is 1048576, depth is 32, parsed names/string values are
limited to 16384 UTF-16 units, and typed collections to 4096 elements. Document
text uses the private ordinary `Mpk.CSharp.Ordinary.BoundaryDocument` byte
carrier. W09 corrected the earlier application-string route, whose 16384-unit
storage could not retain complete larger documents. Application string storage
and the registered value vocabulary remain unchanged. The historical W07
receipt is retained; current contract/run hashes and the archived previous
values are linked in `../ordinary-foundation/boundary-documents/linkage-correction.json`.

Each field gets explicit required/missing/null/value implications, typed payload
canonicality, reconstruction and source-domain goals. The retained contract
resolves exact UTF-16 names, frozen defaults, source types and codec parameters.
Missing is distinct from present null, and null implies presence. Output equations
are scoped to returns reachable from the selected source under accepted boundary
inputs and method preconditions, using the pending W02-W06 source summary. Output goals
require complete canonical encoding, fixed limits, a public reparsed value and
field-complete source observation equality. The formatting-defined guard does
not assume reparse equality, so a lossy codec cannot discharge the equation.
The equality recipe normalizes array snapshots to immutable sequences and
frozen decimal value scale; all other fields, tags, order and floating bits
remain observable.

`BoundaryRunVcProgram` independently reproduces a T05 input/output run before
constructing typed literal definitions and pending reconstruction/round-trip
goals. It retains the canonical contract, both captures, the cumulative
manifest/artifact chain, exact canonical input/output documents and typed
values. Its identity binds the source VIR and static boundary-program digest.
Original raw media remain bound by their byte hash, length and provenance in
the input capture; they are revalidated from retained raw bytes. This is linkage
of the original media and canonical representation, not proof that an adapter
interpreted arbitrary media correctly. Run import rederives every field and
rejects omitted goals, changed values, spliced captures or altered evidence.
Literal value cells are counted as well as formula nodes, and the run handoff
has a 16 MiB transport limit.

The original boundary fixtures are reused without altering any captured facts.
`goldens.json` pins 15 accepted source-contract programs from the 56-row T05
attachment corpus. `run-goldens.json` pins complete product and unit runs from
T05 output captures. Tests check typed terms and constant signatures, the
three-state truth table, positive/broken encoder equations, field-complete
literal comparisons, hostile serializer/evidence edits and deterministic
single-byte input mutations. Existing parser/codec, scalar/sum/collection,
depth/count/byte-limit and source provenance tests run locally as well.

Control and exception VC contract readers now use the existing lossless
canonical parser, allowing boundary field names containing lone UTF-16
surrogates. Earlier handoff goldens, receipts and the frozen producer/vector
package are preserved.

This is a pending ordinary-recipe handoff. It neither certifies source execution
nor uses serializer output as proof authority. W09 owns ordinary expansion,
proof construction and both checker runs; certificates will prove only the
ordinary relation over the linked typed values. The full `./scripts/check-fast.sh`
gate is deferred to the final T06-W12.
