# Concrete Go operation signature draft

This W04 draft derives complete monomorphic input/output and region interfaces
for all 56 logical families in the unchanged [operation table](../operation-table.json).
The [catalogue](catalog.json) closes root/parameter/type/region/obligation and
binding-requirement shapes, with exact production, validator, VC and test
owners for every family. The [definitions](definitions.json) are typed unproved
signature candidates. They are not executable VIR, checked ordinary operation
bodies or independently reconstructed source semantics. W04 remains open.

`mpk.go.operation_definition.v1` and `MPK-GO-OPERATION-DEFINITION-1.0` are new
candidate names, disjoint from every earlier Go and reserved C# identity and
domain. The whole root except `operation_hash` enters the domain-NUL canonical
preimage. Full typed semantic context, raw-capture/source-scope/function/
signature/type-definition/global-U references, original operation-table hash,
exact tag/parameters, ordered interfaces, all rule members and binding
requirements participate. Unknown fields/tags, altered payloads, crossed
contexts and rehashed substitutions reject against complete reconstruction.

The [constructor and reference consumer](../../../../probes/go-practical/operation_signatures.py)
use the preceding closed scope/carrier model. All type arguments resolve to
captured concrete source IDs; source names and implicit generic variables do
not enter a signature. The six operation-type arms are source value, internal
location, joint result product, ordered assignment values, complete state and
abrupt-control result. Internal locations are model handles, not admitted Go
pointers. Source IDs preserve nominal identity even where core carriers agree.
The source-specific constructor derives types; a caller cannot supply an
alternative input/result type, operation allowlist or ordinary axiom.
Every selected function input/result must satisfy Root under that same U.
The one-case U admits the fixture's Plain error backing; adding SliceError
rejects its `[]error` input. A separate valid Quote scope exercises two-target
dispatch. Signature validity cannot be borrowed from another error universe.

The model retains one fixture source/overlay, native type/header facts, literal
module metadata and six synthetic boundary shapes from the preceding work.
Its 56 definitions are component queries, not 56 literal source operations in
one captured function. There is no general parser, complete project capture,
SSA graph, owner allocator, finite-id proof or independently derived source
closure. Actual VIR must bind concrete operations to complete checked source,
control, call, storage and ordinary definitions. A signature index cannot
replace those definitions or authorize source behavior.

Word operations retain exact source widths, signedness and nominal IDs.
Integer constants retain canonical full decimal values and source
representability; they never wrap while being materialized. Explicit
conversions follow the closed integer/Bool/string/identical-underlying
aggregate/slice whitelist, with source-name identity retained inside fields.
Assignment uses tag-sensitive identity and Go assignability rather than that
explicit conversion relation. Comparison excludes noncomparable nested
error/slice paths. Fields use exact nonblank ordinals. Initializer order stays
as supplied, including keyed zero-filled gaps.

Short-circuit RHS computation is a guarded state region. Switch clauses retain
ordered groups of case expressions, one body per group and the separate
physical default position. Default placement does not change test priority.
Comparable array/struct tags retain their complete equality interface;
nil-only error/slice switches require source-checked normalization through
the corresponding closed nil test before Boolean dispatch.
For-loop init/post regions return state; the body returns control. An absent
test has no executed test region and requires canonical true. Array range can
omit array evaluation only in the constant-length mode without a second
nonblank value; its source constant-expression premise still needs proof.
Slice range always takes a descriptor/state input, with current element reads
inside the body. Array-size constant cases route to the retained constant
operation; the runtime operation retains operand evaluation.

Break selects the innermost loop or switch; continue selects the innermost
loop through switches. The private supplied control stack checks source,
function bounds, nesting and exact retained loop spans. Switch entries remain
supplied syntactic contexts rather than independently parsed switch facts;
the test's synthetic nested switch demonstrates only target selection.
Production reconstruction must prove the complete lexical control stack.
Control signatures do not prove that a break test was false or that a return
ran a loop post operation.

Static calls retain exact declaration/signature IDs, receiver-first arguments
and ordered joint results plus post-state. Projection repeats that interface.
These type shapes do not prove same-invocation provenance; actual invocation,
SSA, callee contract, precondition, frame and totality links remain mandatory.
Returned function products have arity 0..16. Ordinary parallel assignments use
a separate ordered value-sequence arm, so 32 targets do not become an invented
function-result limit. Blank targets omit their store handle while preserving
the entire RHS evaluation interface.

Error boxing stays distinct from nil and invokes no method. Error invocation
includes every exact target signature in the same complete global U, plus the
nil-receiver check and required call/footprint proofs. The two prefix/suffix
components pin the exact Go 1.25.0 symbol, compiler inventory and original
`strings`/`internal/stringslite` source bytes. Those are binding requirements;
the source/value equations are unproved, and package-name matching supplies
no trusted adapter or executable implementation.

Every family retains all six common ordinary proof members and its exact
runtime-safety, profile-domain and permission members. Compound assignment
also inherits the chosen divide/shift/arithmetic operation and store checks.
Full-width shift counts have no word-width ceiling; signed min/-1 division
does not gain a fabricated overflow panic. Concatenation and no-growth append
remain profile-domain obligations. NoAccess confers no write permission;
copy/append retain conditional positive-write/read requirements.
The rule-member strings are an exact inventory, not checked proposition terms.
T02–T06 must construct and prove the actual ordinary predicates/equations.

Large case/assignment/append-value parameter lists use the existing complete
source syntax ceiling, not new semantic maxima. An append of 129 values can
form a typed candidate even though its no-growth domain is unprovable within
the 128-cell model. Profile/literal materialization restrictions remain
distinct from Go panic safety. Production transport/resource counters and
actual source-size counting are still separate obligations.

The [224 vectors](vectors.json) cover every family with one typed candidate,
one extra parameter, one altered signature and one missing ordinary member.
All 56 candidates remain unproved; all 168 rehashed altered records reject as
configuration errors. The
[24 selected tests](../../../../probes/go-practical/test_operation_signatures.py)
also cover nominal crossings, full-width constants, inherited compound checks,
guarded/switch regions, result arities,32-value assignment, finite error
dispatch, exact adapter sources, NoAccess, Plain views, range evaluation,
abrupt targets, domain-versus-panic and mutable prototype authority.

The [local replay](../../../../probes/go-practical/run_operation_signatures.py)
reconstructs the whole corpus and compares 56 full canonical preimages between
Python and the unchanged Rust/Go observers, each run twice identically. The
[receipt](observations.json) pins 587 source/data inputs, the preceding contract
receipt and the same 14,496-file Go 1.25.0 inventory. Canonical/hash agreement is
neither source correctness nor checker acceptance. The
[verification record](verification/verification.json) retains local logs and
selection reasons; predecessor receipts and all 143 inventoried files stay
unchanged. No Rust/Go source was edited.

Complete shared VIR/VC/map/manifest/policy/API/release roots and unions, actual
source/control/SSA/ordinary-definition linkage, and producer/consumer migration
review remain required. W05 owns inactive publication and the cumulative T01
gate. All T02–T11 implementation/application/release work remains active.
