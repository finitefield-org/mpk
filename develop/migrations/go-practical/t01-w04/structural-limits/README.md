## 2. Fixed abstract weights

The [shape/accounting model](../../../../probes/go-practical/structural_counters.py)
uses abstract carrier units, not Go bytes, RSS or proof cost:

| Value/role | Weight |
| --- | ---: |
| Bool or full admitted word | 1 |
| Bounded byte string | 257: length plus all256 byte slots |
| Slice descriptor | 37: tag/reference/offset/length/capacity plus16 tag/index path pairs |
| Typed captured/binding location | 33: reference plus16 tag/index pairs |
| Array | 1+n*W(element) |
| Struct | 1+sum W(fields) |
| Closed error | 1+sum W(all global-U payloads), independent of active case |
| Named/alias type | W(resolved underlying), preserving Go nominal/alias identity |
| Owner, scope, packet or snapshot-observation header | 1 |

All declared graph edges are validated, even for zero arrays or inactive error
payloads. Arrays/structs retain the predecessor256/64 ceilings. The successor
depth candidate16 counts array/slice/field/error-payload edges; aliases add
zero. The old array/struct depth meaning is preserved. Complete global-U
plainness prevents references hidden in []error. Duplicate/unknown/cyclic
layouts reject. Saturating arithmetic caps a computed weight before huge
products expand; a saturated count is explicitly a lower bound, not an exact
size. Zero arrays can cost one while their full element graph remains valid.

Per-value candidate:2,097,152 units. It covers a full16-result product of
[256]string values (1,052,689 units). Current and individual past-store
candidates are8,388,608 units; all current/past stores together have33,554,432.
These separate fourfold composition budgets do not guarantee all combinations
of individual maxima fit. A256-element array of64-string structs has4,210,945
units and exceeds the per-value candidate despite fitting each axis.

The per-value ceiling applies to source roots, inline/observation values and
each materialized Plain heap cell. A backing collection is charged against
store totals rather than mistakenly treated as one source value. For example,
128 cells of a64-string struct cost2,105,474 owner units; each cell costs16,449
and the current-store budget can still fit. Empty cells/aggregates have a
nonzero shape/header cost. Unit counts are not a native allocation guarantee.

## 3. Charge complete current and past state

Accounting derives from all represented owners, scopes, source bindings,
active entry arguments, pending operands/joint results/captured targets and
entry/post snapshots. No supplied live set can omit aliases. Each value copy
is charged; shared backing is charged once per store namespace. Distinct
immutable past namespaces count separately even when their data are equal.
Shared past storage does not erase distinct observation packets. Mutable or
cyclic past stores reject. Dead records not yet retired are conservatively
charged; production preflight/retirement needs its own proof.

The retained original Quote type facts give input weights257/37/1 and result
weights2/2. A Quote-shaped private frame with128 borrowed Line cells costs
1,024 current units plus554 past units. Return evidence costs1,421 total
units including its two past stores. This is constructed-frame accounting,
not execution or a proof of Quote. Packed distant windows keep four current
cells while charging the original256-cell return-post storage (416 total
units). One thousand allocation iterations have111 peak/36 final units and
the scalar sum499500; ghost serial/history are excluded from semantic units.
Canonical finite-ID normalization, source lifetime/closure and allocator
correspondence are still unproved. Constant units do not imply constant
memory of the Python prototype or the Go process.
