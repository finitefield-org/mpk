# Shared VIR/contract and whole Go module draft

This W04 draft closes the five-profile module and contract envelopes. The
[catalogue](schema.json) specifies exact required fields, tagged payloads,
hash preimages, profile contracts and planned production owners. Seven
[module candidates](modules.json) cover the four retained profiles, both
Rust targets and practical Go with two actual overlays or entirely derived
default contracts. All source/ordinary proofs and the complete shared family
remain required; these Go candidates establish no application claim.

The common roots are `mpk.vir.v3` / `MPK-VIR-3.0` and
`mpk.contract.v3` / `MPK-CONTRACT-3.0`. Each has exactly five fields: schema,
full typed semantic context, compiled profile-contract identity, tagged
program/contract payload and its own hash. Every other required field enters
the canonical preimage, including schema. Dispatch follows validated registry,
entry, parameters and foundation linkage, then the exact compiled
`mpk.profile.vir.<profile>.v2` identity. A language string, caller extension,
rehash or old/future schema cannot select another arm.

Retained arms use their existing unit/function/typed core structures, wrapped
with exact common contract roots. Before any private old-family projection,
every static call must reference the exact new-family callee contract hash.
The consumer never accepts an old root as a common v3 module. Rehashing old
contracts is an explicit observation conversion after those checks; it is not
a compatibility acceptance path.

The practical-Go program binds one capture, a source-scope set, the complete
common contracts and typed function bodies. Five new Go identities avoid all
earlier Go and reserved inactive C# identities:

The preceding source-overlay v1, contract-scope v1, normalized-contract v1,
operation-definition v1 and function-body v1 bytes/meanings stay unchanged.
The new scope requires a nullable overlay-object ID. The new normalized
contract binds that scope and an exact `default` or `source_overlay` origin.
New concrete operations bind the same scope/capture; new bodies bind the common
contract v3 and concrete operations v2. The preceding 70 expression arms,
56 operation meanings and seven structured-body node arms are retained.

The [project assembler](../../../../probes/go-practical/shared_project.py)
reconstructs a single immutable fixture capture from original source facts,
literal Go/go.mod objects and every actual raw overlay. Raw paths and bytes
are bound before capture-dependent identities. Every scope shares that capture;
binding IDs, loop references, type-definition envelopes, operations, contracts
and bodies are recomputed. Changing overlay whitespace changes all dependent
IDs while preserving declaration/signature identities. Alias-resolved duplicate
roots/overlays and duplicate/noncanonical paths reject.

An unannotated function has no fabricated overlay object or raw sidecar.
Its derived contract is partial, requires nothing, ensures logical true and
admits every same-U error case at every error-bearing input path. Ordinary
entry validity/bounds remain required. A default is an unproved candidate:
calls require the callee's actual source-body-and-contract relation. It grants
no trusted callee theorem. The two-overlay candidate includes an unannotated
Error method as a body dependency under the same whole capture.

The [module consumer](../../../../probes/go-practical/shared_vir.py) reconstructs
the authority from immutable input bytes, then independently recomputes all
scopes, contracts, operations, bodies and obligation sites. Body, scope and
contract sets are exact and declaration-ordered. Traversal begins at every
selected root; missing callees, cycles and unreachable extra bodies reject.
All nine nodes and three regions of each Go candidate count across its three
functions toward the existing module instruction/block caps. Existing per-body
counters remain in force. Full general production accounting remains due.

Source facts still cover only the preceding pinned single Go fixture package;
multiple raw overlays are supported within that captured model. This is not
a general project importer. The candidate Quote and Error bodies are typed
graphs, not source-equivalent translations. InputErrors retains the preceding
discard-only normal-exit candidate whose erasure proof is still missing.
Source/call/control/lifetime/activation correspondence and all ordinary
operation, permission, frame and totality proofs remain T02–T06 work.

unit; the receipt records those settings and native binary hashes. The bridge calls
the actual unchanged retained importer, projection, type validator and
profile-specific WP engine. It only serializes observations and adds no kernel,

typed projection and serialized VC data, including safety origins, members and
dependency fields. This is fixture preservation evidence, not a universal
preservation theorem or proof discharge. Thirteen actual native queries include
