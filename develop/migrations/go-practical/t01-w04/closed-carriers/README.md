actual bits. Source int/uint retain their target64 width and distinct source
identities. A string has a full64 length and256 arbitrary byte slots, each

interpretation. Positive fixed arrays use the next power-of-two index space;
their actual length stays in the source identity, and padding validity is
separate. Structs and result products preserve every ordered component.

A binary heterogeneous product is
`(tag : Bool) -> Bool.recType A B tag`. Empty products and zero-length arrays
use a Bool dummy whose sole canonical valid value is false. That requirement
is not an extra source value; the checked zero law enforces this choice for
the generated zero. Arbitrary input validity still needs separate predicates
and source proofs. No function extensionality or product eta rule is added.

function-type alias. Generated binder/result types therefore expose their Pi

evidence members. Consumers must retain that exposure when reconstructing
ordinary declarations. No new application-reduction rule is assumed.
