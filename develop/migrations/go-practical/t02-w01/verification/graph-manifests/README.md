# Independent original dependency manifest facts

The [Rust dependency reader](../../../../../../crates/mpk-vc/src/go_practical_type_keys/module_observations/manifest/lax.rs)
derives original dependency go.mod facts with the pinned ParseLax disposition.
It owns the complete original source buffer and preserves optional/unchecked
module declarations, ordered duplicate requirements, raw retractions and ignore
paths. Unknown and main-only directives/blocks remain original source syntax
without acquiring replacement/exclusion/toolchain authority. Lexical failures
still reject, including inside ignored statements. Multiword/unknown blocks are
parsed before their ignored semantic disposition.

The dependency version reader retains native lax major.minor correction, byte
suffixes, exact accepted Go-version spellings, pruning and implicit virtual go
requirements, and whether the fixed compiler is too old. Modfile syntax accepts
some Go spellings that the semantic version comparator considers invalid; the
two layers stay distinct. Unbounded decimal strings retain the original version
domain. Retraction syntax ignored by the native dependency parser stays ignored,
and accepted trailing fields do not change original bytes. Missing module/go
directives remain distinct from present empty values. No strict selected-module
admission policy is imposed on graph-only original manifests.

The [native oracle](../../../../../../go-tools/go2vir/practical_graph_manifest_oracle_test.go)

labels, plus123 new dependency cases. All779 native/Rust verdicts and complete
fact rows agree:376 accept and403 reject. The [library correspondence](library-correspondence.json)
records all eight original files for modfile/module/semver/lazyregexp as
byte-identical between the complete pinned Go1.25 SDK and the producer vendor
tree. No alternate parser implementation is substituted as the native oracle.

Original initial/final graph snapshots reopen complete saved source objects,
including unselected old and zero-requirement leaves and versioned replacements.

and appends the implicit go edge, comparing exact native order and duplicates.
The original graph owner independently imports every source/export/module input:

Its manifests supply the same source-derived facts without importing the native
graph's parser projection as an authority. Virtual nodes retain no invented file.
