retains its complete native Go command output, diagnostics, logical package/
export locations and original root names under the same lock as the source
capture. The caller cannot supply replacement metadata, sources, typed packages
or export callbacks. The existing capture entry point delegates to the same
locked implementation. Returned buffers remain independent after owner retirement.

The [independent Rust reader](../../../../../../crates/mpk-vc/src/go_practical_type_keys/export_inputs.rs)

provenance labels, complete source package set and original export buffers. It
reconstructs active/excluded/test source, all nine auxiliary classes, production
resource patterns/files and direct imports from original bytes. SDK vendor
resolution retains original source import order. Physical-origin strings bind
command paths to exact logical capabilities; they do not authorize those roots.
Duplicate native fields reject before a typed decoder can erase them. The
original metadata remains whole, including fields outside the checked projection.

Every non-intrinsic original source package needs exactly one captured export.
Unsafe retains its actual original source and intrinsic disposition without a
fabricated export. All imported packages must be in the same closed set. The
selected root must match the original command. Generated/failed/cgo packages,
crossed source lists/locations/import maps/resources and unbound export objects
reject. Each original archive retains every member; its member bounds, package
definition, Linux/amd64/Go1.25 target header, recorded build ID and padding are
checked against the actual original metadata. Archive bytes and signature
metadata do not establish source execution or compiler authenticity.
