accepts an original package path and exact physical expression span. It resolves
one addressable expression from the owned original Go type universe, verifies
full source/package membership and original bytes, and retains image/compiler/
module identities. It accepts no caller AST, typed package, adapter, import
callback, replacement bytes or supplied path. Original preparation roots and
the donor replay image are retired before these queries. Returned complete
source buffers, declarations, type fields and expression bytes are independently
owned; modifying them cannot change subsequent observations.

Promoted fields expand into every actual nonpointer field ordinal. Array and
slice indices retain their exact original expression spans, native/defaulted
type, full signedness/width and complete constant values; an absent constant
means a runtime expression. No runtime index is narrowed or evaluated by the
observer. Slice indexing pivots to the complete descriptor expression before
extending the backing route, including constructed or resliced descriptors.
It never traverses a descriptor as a product field or invents a writable child
heap. The pivot still needs actual owner/path/offset/capacity, safe-access,
evaluation-order and combined-path-length bindings. Variable declarations and
local/package scope labels supply no allocation, ownership or lifetime fact.
