# T02-W01 private original-source type keys

The [Go producer](../../../../../../go-tools/go2vir/practical_type_keys.go)
accepts only an original package path and exact physical expression span. Its
owned original Go universe supplies every source object, active package source
set, module go.mod object, physical TypeSpec declaration, alias target, nominal
binding and structural child. Neither native display names nor physical
preparation paths enter key preimages. Returned bytes cannot mutate that owner;
retired owners and inexact spans reject. The package key is a private type-scope
component, not a complete module instance, capture context or build selection.

The [Rust importer](../../../../../../crates/mpk-vc/src/go_practical_type_keys.rs)
independently checks exact required/nullable fields, duplicate-free strict JSON,
domain-separated canonical hashes, whole owned original source bytes, logical
paths and the eight current source kinds, canonical ordering, exact member and
reference closure, alias/nominal separation, complete underlying links, and
expanded nonrecursive structural geometry. It rejects zero-array and slice
cycles, hidden missing edges, arrays over256, fields over64 and depth over16.
Geometry counts every child; this does not supply the complete global-error-U,
Plain, weight, final expanded depth or artifact4096-declaration proof. The
candidate construction budget remains the existing source syntax budget.

The old frozen source_type.v1 draft omitted the embedded-field flag. Pinned
Go1.25.0 go/types/predicates.go compares that flag when comparing struct types.
The new private source_type.v2 preimage therefore includes `embedded` and raw
`tag_bytes_hex`. Embedded `struct{T}` and direct `struct{T T}` remain different.
Raw FF and UTF-8 replacement-character tags remain different. Package-local
unexported field identities use the exact pinned Unicode15.0.0 Lu category;
titlecase and modifier-uppercase letters are not exported. The complete L/Nd/Lu
range arrays match the [original pinned source](unicode-check/result.json),
with [Go's SDK license](GO-SDK-LICENSE.txt). Native `int`/`int64` and
`uint`/`uint64` remain distinct despite equal widths. Predeclared byte/rune
aliases resolve to uint8/int32. User aliases retain physical declaration edges
but mint no distinct semantic type key. Source-alias observations remain in the
native observer; anonymous `struct{Value Alias}` and `struct{Value Target}`
share the semantic key. New private type_package.v2/type_declaration.v2/
type_components.v2 identities do not relabel old records. All255 frozen design
inputs remain byte-exact, including the old draft; its obsolete source-kind
spelling is rejected by this importer rather than restored.
