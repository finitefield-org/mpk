# Go and Rust language scope amendment

The user authorized Go and Rust as MPK's only program source languages on
2026-10-20. The basis is commit `528b599aacfe439d4abd8f50e046a754c9a24435`.
The normative scope is [LANGUAGE_SUPPORT_SCOPE_V1.md](../../specs/LANGUAGE_SUPPORT_SCOPE_V1.md).
This is an intermediate checkpoint within Go T02-W01; it completes neither
W01/R06 nor T02. The remaining source/program foundation and T02–T11 work
continue in their existing priority order.

## Implementation scope

Dedicated Java/C# implementations, fixtures, examples, registrations,
launchers, build-input materializers, specifications and test owners are
removed. Dedicated current probe directories and the C# replay helper/test
are retired into full original-byte evidence, without executing their tests.
Compiled CLI/API/VC and release dispatch contain Go/Rust only.
Unknown and retired languages reject at profile lookup before source capture
or output creation. Python/shell build tools and browser application code
remain tools/application code rather than MPK language profiles.

Installed semantic registry revision 4 contains unchanged Go fixed and Rust
checked entries. The release registry has two frontend/toolchain pairs and
three tuples: Go linux/amd64 and Rust i686/x86_64 Linux GNU. Changed frontend
identities use new bundle IDs; old inventory identities are not overwritten.
New compiled identities require real frontend rebuilds and fresh artifact
hashes. A structural registry check alone does not establish installed or
native release acceptance.

Practical Go's future shared family covers four target contexts: Go fixed,
practical Go, Rust32 and Rust64. Every common member, the 56 Go source
families, all 19 theorem families, all 169 demands and their complete
source/type/operation/storage/lifetime/state/program bindings remain due.
Kernel caps remain 4,096 declarations, 131,072 terms, 2,097,152 certificate bytes and
1,024 fuel; Go budgets are unchanged. No practical Go profile activates here.
