# Retired multi-language implementation plan

MPK supports [Go and Rust only](../specs/LANGUAGE_SUPPORT_SCOPE_V1.md).
Other-language implementation, resumption and release tasks have been removed
from the current plan. Continue the [Go work plan](09_go_practical_subset_design-todo.md)
and the [Rust design](05_rust_frontend_design.md).

The [complete original record](../migrations/go-rust-only/historical-plans/06_multilanguage_frontend_design-todo.md.original)
is retained as historical evidence. It provides no current frontend support,
release acceptance, future language task or prerequisite for Go/Rust work.
