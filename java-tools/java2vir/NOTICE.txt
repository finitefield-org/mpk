MPK java2vir is an untrusted frontend in the private JAVA-03 release candidate.
The MPK project sources are distributed under Apache-2.0.

This candidate contains only MPK classes, its manifest, and this notice.
It is compiled with the exact Eclipse Temurin JDK pinned in
develop/specs/JAVA_PROFILE_V0.md. No JDK or third-party class is bundled in
java2vir.jar. The private runtime bundle preserves the JDK archive's complete
legal notice bytes, including regular copies of the frozen legal link targets.

The candidate is not part of the active public release registry. A successful
build, version check, or frontend lowering result is not a proof verdict.
